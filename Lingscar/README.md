# Lingscar — Website Redesign

A website redesign project focused on improving usability, navigation and the overall digital experience.

---

### The Project

Lingscar explores how a website experience can be made clearer and more intuitive through thoughtful UX decisions. The project began with a website audit to identify usability issues and opportunities for improvement, followed by a redesigned interface.

---

### The Design Direction

The redesign focuses on creating a more structured and user-friendly experience. Through improved information hierarchy, clearer navigation and refined layouts, the interface aims to make content easier to discover and interactions more straightforward.

---

### Project Details

* **Category:** UX/UI Design
* **Industry:** Automotive
* **Focus:** Website Audit, UX Research, Website Redesign, Interface Design
* **Tools:** Figma
